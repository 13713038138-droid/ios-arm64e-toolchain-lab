# Long-project evidence management

Activation: use when the development task concerns ios context keeper. Read only this specialist reference when relevant.

Before editing, reconstruct the most recent accepted baseline, SHA256, previous failed variants, known runtime facts and pending hypotheses. Create machine-readable checkpoint with current repo commit, source provenance, key offsets, tests, device result and NEXT STEP. Never claim the summary itself is proof. When context compacts, preserve failures and excluded paths, not just successful outcomes.

## Required handoff
- Inputs and exact provenance (file, revision or trace).
- Confirmed behavior and separate hypotheses.
- Minimal patch, commands actually executed and negative controls.
- Remaining blocker, install/release decision and rollback.
