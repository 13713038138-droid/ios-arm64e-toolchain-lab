# Interface and accessibility specialist

Activation: use when the development task concerns ui ux accessibility. Read only this specialist reference when relevant.

Maintain visual consistency with original app; prefer standard controls for navigation and transparency. Test dynamic type, VoiceOver, keyboard input, rotation, haptics, dark mode and reduced motion. Use screenshot-based before/after comparisons rather than subjective improvement claims. Preserve existing interaction semantics unless the user requested change.

## Required handoff
- Inputs and exact provenance (file, revision or trace).
- Confirmed behavior and separate hypotheses.
- Minimal patch, commands actually executed and negative controls.
- Remaining blocker, install/release decision and rollback.
