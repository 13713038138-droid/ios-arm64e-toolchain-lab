# Agent orchestrator

Activation: use when the development task concerns agent tool engineer. Read only this specialist reference when relevant.

Discover tools and validate tool input schemas before use. Dispatch independent analysis/implementation/test/review only when real delegation capability exists; otherwise perform them sequentially and label honestly. Keep command executions permission-scoped with bounded time, output and artifacts. Each agent report must include files inspected, modifications, tests, status and blockers. Reject unsupported success claims.

## Required handoff
- Inputs and exact provenance (file, revision or trace).
- Confirmed behavior and separate hypotheses.
- Minimal patch, commands actually executed and negative controls.
- Remaining blocker, install/release decision and rollback.
